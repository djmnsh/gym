# מעקב אימונים – העלאה ל-GitHub Pages

## מה יש בתיקייה
- `index.html` – האפליקציה
- `manifest.webmanifest`, `sw.js` – מאפשרים התקנה כאפליקציה ועבודה בלי קליטה
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `favicon-32.png` – האייקון

## העלאה (פעם אחת, הכי נוח ממחשב)
1. נכנסים ל-github.com ופותחים חשבון (אם אין).
2. לוחצים **+** למעלה ← **New repository**. שם: `gym`. מסמנים **Public** ← **Create repository**.
3. בעמוד שנפתח לוחצים **uploading an existing file**, גוררים את **כל הקבצים** שבתיקייה (לא את התיקייה עצמה) ← **Commit changes**.
4. **Settings** ← **Pages** (בתפריט השמאלי). תחת Branch בוחרים **main** ו-**/(root)** ← **Save**.
5. אחרי דקה-שתיים הכתובת תופיע למעלה: `https://<שם-המשתמש>.github.io/gym/`

## התקנה באייפון
1. פותחים את הכתובת ב-**Safari** (לא בכרום).
2. כפתור **שתף** ← **הוסף למסך הבית** ← **הוסף**.
3. מעכשיו פותחים מהאייקון הכתום.

## העברת האימונים הקיימים
1. בגרסה הישנה (בתוך Claude): לשונית **תרגילים** ← גלילה למטה ← **ייצוא** ← **העתק**.
2. באפליקציה החדשה: **תרגילים** ← **יבוא** ← מדביקים ← **יבא והחלף את הנתונים כאן**.

## חשוב
- הנתונים נשמרים בטלפון בלבד. מחיקת האייקון ממסך הבית מוחקת אותם, לכן כדאי לייצא גיבוי מדי פעם.
- עדכון גרסה: מעלים את `index.html` החדש לאותו מאגר (Add file ← Upload files). הנתונים נשמרים.
